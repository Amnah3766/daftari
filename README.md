# دفتري

دفتر طلبات المشاريع المنزلية بالكويت: منو دفع، منو باقي، كم كاش عند المندوب، وكم ربحت صج.

MVP لمشروع FinTech (CODED · UniCODE · Web with AI، اليوم السابع).

## المشكلة

المشاريع المنزلية بالكويت (حلويات، شموع، عطور) تسجل طلباتها بالواتساب. الزبون يدفع مرة برابط ومرة تحويل ومرة كاش مع المندوب،
فيضيع منو دفع ومنو باقي، وكم كاش للحين عند المندوب، وآخر الشهر صاحبة المشروع ما تعرف كم ربحت صج.

## ميزات الـ MVP

- **حساب بالإيميل وكلمة السر:** تسجيل جديد، دخول، خروج. كل مشروع يشوف طلباته بس.
- **تسجيل طلب:** اسم الزبون، رقمه، المنتج، السعر بالدينار، التكلفة، وطريقة الدفع (رابط / كاش مع المندوب / تحويل).
- **«باقي ما دفعوا»:** زر تذكير بالواتساب برسالة مؤدبة جاهزة، وأزرار الحالة: ما دفع ← عند المندوب ← وصلني (مع تراجع).
- **لوحة الشهر:** مبيعات الشهر، الربح الصافي من الطلبات اللي وصلت فلوسها، الكاش اللي عند المندوب، واللي باقي عند الزبائن.
- **رابط الدفع (ملاحظة المدرس، اليوم السادس):** كل طلب طريقته «رابط دفع» ياخذ رابط خاص فيه (`/pay?t=…`) ينرسل للزبون
  مع تذكير الواتساب (أو «نسخ رابط الدفع»). الزبون يفتح صفحة الدفع ويدفع بالبطاقة، فتطلع له **«تم الدفع ✓»** أو **«انرفض الدفع ✗»**.
  أول ما يدفع، الطلب يصير **«وصلني» لحاله** عند صاحبة المشروع بدون ما تضغط شي (الصفحة تتحدث كل 5 ثواني وتطلع تنبيه)،
  وإذا البطاقة انرفضت يطلع لها «الزبون حاول يدفع والدفع انرفض».
  - **بدون مفتاح Stripe** (الوضع الافتراضي): بوابة دفع تجريبية داخل دفتري. بطاقة `4242 4242 4242 4242` تنجح،
    و`4000 0000 0000 0002` تنرفض. رقم البطاقة ما يطلع من المتصفح، وما ينخصم أي مبلغ.
  - **مع `STRIPE_SECRET_KEY` (مفتاح اختبار sk_test بس):** الزبون يروح لصفحة Stripe Checkout (وضع الاختبار). لما يرجع،
    السيرفر يسأل Stripe بنفسه ويتأكد إن الجلسة مدفوعة ولنفس الطلب ونفس المبلغ، وبعدين يحوّل الطلب «وصلني».
    الحساب التجريبي ما يقبل الدينار، فالمبلغ ينخصم بالدولار بسعر ثابت (1 د.ك = 3.25 $).

الأرقام تنكتب بالعربي أو بالإنجليزي (١٢٫٥ أو 12.5)، والمبالغ بالدينار لين 3 خانات (فلس).

## التقنيات

- **الواجهة:** HTML + CSS + JavaScript بدون أي مكتبة (`public/`)، عربي من اليمين لليسار ومصممة للموبايل أول.
- **السيرفر:** Node بدون إطار عمل. ثلاث نقاط: `/api/auth` و `/api/orders` و `/api/pay` (رابط الدفع العام) في `lib/handlers.js`.
  - على **Vercel**: `api/auth.js` و `api/orders.js` و `api/pay.js` (Serverless Functions).
  - Stripe عن طريق `fetch` مباشرة (`lib/stripe.js`) بدون مكتبة إضافية.
  - على جهازك: `server.mjs` (نفس الكود).
- **البيانات بـ MongoDB Atlas:** `users` و `sessions` و `orders`. كل طلب مربوط بصاحبه، وكل استعلام يتفلتر بصاحب الحساب.
- **الأمان:** كلمات السر مشفرة بـ scrypt، والجلسة بكوكي HttpOnly، وحماية من CSRF، وقفل الحساب 15 دقيقة بعد 5 محاولات غلط.

## الإعدادات (بدون أسرار بالكود)

| المكان | وين تحط `MONGODB_URI` (و `STRIPE_SECRET_KEY` اختياري) |
|---|---|
| Vercel | Settings ← Environment Variables |
| جهازك | ملف `.env.local` (انسخ `.env.example`) |

وبـ MongoDB Atlas ← Network Access لازم يكون مسموح `0.0.0.0/0`، لأن عناوين سيرفرات Vercel تتغير.

## التشغيل

```bash
npm install     # مكتبة وحدة: mongodb
npm start       # http://localhost:5320
npm test        # 49 اختبار: المبالغ، الحسابات وقفلها، فصل بيانات كل مشروع، الـ API، ورابط الدفع (البوابة التجريبية + Stripe وهمي)
node scripts/smoke.mjs https://daftari-amnah3766.vercel.app   # فحص الموقع المنشور (35 فحص، منها رابط الدفع)
```

## الرؤية (مو بالـ MVP)

ربط بوابة دفع كويتية حقيقية (KNET عن طريق Tap أو MyFatoorah) بدل وضع الاختبار، مع Webhook يأكد الدفع حتى لو الزبون سكّر الصفحة،
وقراءة طلبات الواتساب بالذكاء الاصطناعي، وتقرير شهري للمشروع يساعده ياخذ تمويل من البنك.
